## 💡 Pro Tips

### Image Quality
- **Resolution**: 1920x1080 (hero), 1024x576+ (others)
- **Format**: PNG (transparent, lossless)
- **Size**: <500KB per image
- **Contrast**: Ensure dark BI theme is visible

### Windows Screenshot Tools
```powershell
# Built-in
Win + Shift + S    # Snip tool
Win + Print        # Screenshot

# Online compression
# https://tinypng.com/

# If you use ShareX (optional)
# Download from: https://getsharex.com/
```
